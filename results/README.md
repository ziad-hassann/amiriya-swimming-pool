# Amiriya Swimming Pool Results

A responsive Arabic swimming-results website for the 25 October 2026 assessment. All events are 50 meters, in a 25-meter pool.

## Features

- Search suggestions and individual swimmer result cards
- Birth-year rankings for each of the four strokes
- NT for missing results; equal times share a rank
- English PNG result cards with stroke illustrations
- Reduced-motion support and bundled fonts

## Run

Serve this directory with any static HTTP server. No build step or server database is required.

## Hosting

For GitHub Pages, select the repository's default branch and the root directory under Settings > Pages. This is a static website.

## Files

- `index.html`: page structure
- `style.css`: responsive styling and animation
- `data.js`: swimmers and recorded times
- `app.js`: search and rankings
- `features.js`: image export and motion effects
- `fonts/`: bundled IBM Plex Sans Arabic font files
